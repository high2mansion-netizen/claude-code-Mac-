Section 01

Claude Code × MacBook Pro M1

M1チップ搭載Macなら、ネイティブインストーラーで最もスムーズにセットアップできます

1

ネイティブインストーラーで一発インストール

Node.js不要。ターミナルを開いて以下を実行するだけです。

# ターミナル（Terminal.app）を開いて実行
curl -fsSL https://code.claude.com/install.sh | sh
💡 M1 Macは ARM64 ネイティブバイナリが自動選択されます。Rosetta変換は不要で、高速に動作します。
2

インストール確認

バージョン番号が表示されれば成功です。

claude --version
3

認証（ブラウザで自動ログイン）

claudeコマンドを実行すると、ブラウザが開いてClaude Pro/Maxアカウントで認証されます。

# プロジェクトフォルダに移動してから起動
cd ~/Documents/my-project
claude
💡 Claude Max プランなら API従量課金ではなく月額固定で利用可能。ヘビーユーザーにはMaxがおすすめ。
4

VS Code連携（オプション）

VS Code拡張機能をインストールすると、エディタ内のターミナルから直接Claude Codeを使えます。

# VS Code のターミナルパネルで
claude

# 複数パネルで並列実行も可能
5

Desktop App（ターミナル不要の選択肢）

ターミナル操作に慣れていない場合は、macOS用のDesktopアプリもあります。GUIでClaude Codeの機能を利用できます。

# ダウンロード先
code.claude.com → macOS版をダウンロード

Section 05

GoodNotes連携ストラテジー

手書きの思考とデジタル教材を一つのノート上でシームレスに統合

🌐 方法 A — リンク参照

GitHub Pages × GoodNotes

Claudeで作ったインタラクティブHTML教材をGitHub Pagesにホスト。URLをGoodNotesに貼り付けて、タップで参照。Claude Codeでデプロイを高速化。

📄 方法 B — PDF取り込み

PDF → GoodNotes直接インポート

フレームワーク一覧、用語集など静的な参照資料はPDFで生成し、GoodNotesにインポート。手書きメモを重ねて理解を深化。

🔄 方法 C — ハイブリッド運用（推奨）

静的PDF + 動的HTMLの組み合わせ

概念の全体像はPDFでGoodNotesに取り込みペンで書き込み。詳細な動的コンテンツはGitHub PagesリンクからタップでアクセF。二つの世界を一冊に統合。
